ThoughtSpot is an agentic analytics and business intelligence platform that turns data into decisions using AI agents (Spotter), Search, automated insights, and embedded analytics. The ThoughtSpot Public REST API v2.0 exposes 191 operations across authentication, users, groups, roles, orgs, metadata (Liveboards, Answers, Models, Tables), search and data, AI/Spotter agents and conversations, connections, custom actions, webhooks, schedules, version control (Git/TML), security and sharing, tags, collections, and system administration. Developers also embed ThoughtSpot with the Visual Embed SDK, build custom charts with the Chart SDK, and connect agents through an official hosted MCP server. This profile was enriched by the API Evangelist pipeline from ThoughtSpot's public developer surface (developers.thoughtspot.com, docs.thoughtspot.com, the thoughtspot GitHub org, npm, and PyPI).

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ThoughtSpot: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
