# ThoughtSpot: Agentic Analytics Platform

> ThoughtSpot is an agentic analytics platform that transforms data into decisions using AI agents, automated insights, and embedded intelligence — enabling every team to get live, explainable answers from their data.

## AI Agents
- [Spotter – AI Analyst Agent](https://www.thoughtspot.com/product/agents/spotter): Conversational AI agent for self-service analytics; ask questions in natural language and get instant, governed answers on live data.
- [SpotterModel](https://www.thoughtspot.com/product/agents/spottermodel): Automated semantic modeling agent that turns raw data into governed semantic models in minutes.
- [SpotterViz](https://www.thoughtspot.com/product/agents/spotterviz): Dashboarding agent that turns data into complete, styled Liveboards automatically.
- [SpotterCode](https://www.thoughtspot.com/product/agents/spottercode): AI-assisted coding agent that generates embed logic and components directly in your IDE.
- [All BI Agents](https://www.thoughtspot.com/product/agents): Overview of the full suite of ThoughtSpot BI Agents.

## Platform Features
- [Semantic Layer](https://www.thoughtspot.com/product/spotter-semantics): AI-native, adaptive semantic layer for trusted metrics, governed accuracy, and agent-ready metadata.
- [AI-Augmented Dashboards](https://www.thoughtspot.com/product/visualize): AI-first Liveboards with drill-anywhere self-service, automated insights, and mobile-ready design.
- [Automated Insights](https://www.thoughtspot.com/product/automated-analytics): Built-in AI that surfaces key trends, drivers, and alerts automatically.
- [Actionable Insights](https://www.thoughtspot.com/product/actionable-analytics): Connect insights directly to actions within existing tools and workflows.
- [Any Data, Anywhere](https://www.thoughtspot.com/product/connect): Connect to any data source with zero-copy, real-time, and in-memory options.
- [Ecosystem](https://www.thoughtspot.com/product/ecosystem): Partner integrations and data stack compatibility.
